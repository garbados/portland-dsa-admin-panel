# @portland-dsa/admin-panel

This repository includes the frontend code for the Portland DSA's chapter admin panel.

To develop:

```bash
# get the source
$ git clone git@github.com:portland-dsa/admin-panel.git
# install dependencies
$ npm i
# run the test suite
$ npm test
# run the development server for live testing
$ npm run dev
```

See [CONTRIBUTING.md](./docs/CONTRIBUTING.md) for more details about submitting changes.

## Repo Contents

- `docs/`: Documentation, including architectural notes and contribution guidelines.
- `src/`: The vanilla JavaScript used to build the frontend.
- `test/`: Where the tests live.
- `public/`: Where the frontend, once built, is written.
