### Contributing – Pilar Frontend

Principles: minimal dependencies, junior‑friendly code, clear readability.

*A volunteer organization inevitably experiences high turnover, so the project must be designed to be reliable, maintainable, and explainable, so that it can pass from maintainer to maintainer without interrupting the organization's processes.*

*As a client-facing application, this frontend should prioritize accessibility, including the use of alt-text, aria metadata, and other affordances to ensure tools like screen readers and mouseless navigation can effectively use the app. This should be asserted in testing.*

- **No LLMs.** (You cannot explain what an LLM does. You do not have mastery if an LLM does it for you. Are we not artisans, comrade?)
- Code style: Vanilla JS in [Standard](https://www.npmjs.com/package/standard/) style.
- Update docs (particularly `README.md` and `docs/ARCHITECTURE.md`) when behavior changes.

Thank you for your contribution!
